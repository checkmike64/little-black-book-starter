# Owner-facing copy guidelines

Owner-facing rationale copy must state what the application can verify from the
current Book record. Use labels such as **Evidence**, **Match basis**, **Profile
facts**, and **Source context**.

Do not use hooks such as “The fit.” or “Why now.” Do not manufacture urgency,
intent, compatibility, or a recommended action from an unsupported model
summary. If the saved fields do not support a conclusion, say which evidence is
missing and ask the owner to review the relevant records.

Generated or imported text is not a fact merely because it was saved. Prefer a
deterministic explanation derived from identified fields or workflow state. A
user-entered domain label such as “Why stay in touch” may remain when it clearly
names the owner’s own saved note rather than an application claim.
