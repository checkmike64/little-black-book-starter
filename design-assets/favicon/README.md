# Little Black Book favicon

This mark is intentionally favicon-only. It is a closed black book with a visible pale page edge, a quiet spine, and one cobalt bookmark. The geometry is drawn on a 32-pixel grid so it remains recognizable at browser-tab scale without becoming a general application icon.

Assets:

- `little-black-book-mark.svg` — editable vector master.
- `favicon-16x16.png` — browser-tab fallback.
- `favicon-32x32.png` — high-density browser-tab fallback.
- `apple-touch-icon.png` — 180-pixel touch bookmark.
- `favicon.ico` — legacy browser fallback.

The live Next.js favicon source is mirrored at `app/icon.svg`.
